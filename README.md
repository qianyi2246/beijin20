```bash
python -m http.server 8000
# http://localhost:8000
```

## 换成自己的照片

编辑 `assets/app.js` 顶部的 `WORKS`：

```js
{
  num: "01",
  src: "images/01.jpg",
  w: 1200, h: 1600,
  title: "晨雾山谷",
  category: "风景",
  alt: "晨雾中层叠的山谷",  // 无障碍描述
}
```

分类颜色在 `CAT_COLORS` 里，四类各有一个色块；新增分类时补一行即可。

首屏右侧三张叠放的照片和标题文字是静态的，在 `index.html` 的 `.hero-stack` 与 `.hero` 里。

## 风格细节

- **12 列拼贴网格**：每个位置有固定的跨列/跨行（`nth-child` 规则），宽窄交替
- **白框 + 黑描边 + 硬阴影**：相框感；悬停时阴影换成红 / 蓝 / 黄绿 / 粉
- **轻微旋转**：每三张一组轮流倾斜，悬停回正
- **洗牌**：点击「洗牌」随机重排所有照片，带一次错落的出现动画
- **分类筛选**：胶囊按钮，带数量；筛选后灯箱只在当前分类里切换

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击照片 / `Enter` | 打开灯箱 |
| 分类胶囊 | 筛选当前分类 |
| 洗牌 | 随机重排 |
| 灯箱内 `←` `→`、`Esc` | 切换 / 关闭 |
| 手机 | 双列拼贴；灯箱左右滑动 |

## 自定义

| 想改什么 | 改哪里 |
| --- | --- |
| 主色（红 / 蓝 / 黄绿 / 粉） | `style.css` 顶部 `:root` |
| 每格占几列 | `.card:nth-child(n)` 的 `grid-column` / `grid-row` |
| 网格行高 | `.grid` 的 `grid-auto-rows` |
| 旋转幅度 | `.card:nth-child(3n…)` 的 `--rot` |
| 分类颜色 | `app.js` 的 `CAT_COLORS` |

## 移动端

窄于 760px 时改成两列、去掉旋转，隐藏分类标签；
标题和拖拽区自动缩小，灯箱改为窄边距。
